## About
A two-screen Android application built for the Mobile Application Development lab task. The app demonstrates **implicit intents** (opening the browser, dialer, and maps) and **explicit intents** (navigating to a second activity), along with input validation using `setError()`.

## Features
- Home screen with UOL logo, name field, and four action buttons
- Implicit intents for website, dialer, and maps
- Explicit intent to a second activity (`RequestActivity`)
- Reusable `openIntent()` helper with try-catch and Toast
- Phone validation (11 digits, starting with 03)
- Link validation with automatic `https://` prefix
- Professional navy-and-gold Material Design

## Tech Stack
Java • XML • Android SDK • Material Components • CardView • TextInputLayout
